# 3GPP GTP Related Protocols and Applications

This is a library and application suite containing relevant protocol codecs and
binaries for a toy Packet Delivery Network Gateway (PGW) with Control- and User
Plane Separation (CUPS). The purpose of the project is to provide me a
playground where I can toy around with implementations from scratch to learn the
internals of the packet-switched components of a telecommunications network.

The project touches on related concepts such as an Evolved Packet Data Gateway
(ePDG) and a Servicing Gateway (SGW) as well.

No code in this project is intended to be used as anything commercial nor as a
reference. It is all written by a hobbyist trying to learn.
